# Print an 'est_change' Class Object

Print the content of an 'est_change'-class object.

## Usage

``` r
# S3 method for class 'est_change'
print(x, digits = 3, first = 10, sort_by = c("gcd", "est"), ...)
```

## Arguments

- x:

  An 'est_change'-class object.

- digits:

  The number of digits after the decimal. Default is 3.

- first:

  Numeric. If not `NULL`, it prints only the first *k* cases, *k* equal
  to `first`. Default is 10.

- sort_by:

  String. Should be `"est"`, `"gcd"`, or `NULL`. If the output was
  generated by
  [`est_change_raw()`](https://sfcheung.github.io/semfindr/reference/est_change_raw.md)
  (DFTHETA or DFZTHETA) or
  [`est_change_raw_approx()`](https://sfcheung.github.io/semfindr/reference/est_change_raw_approx.md)
  (approximate DFTHETA) and `sort_by` is not `NULL`, then each column is
  sorted individually, with case IDs inserted before each column. If the
  output was generated by
  [`est_change()`](https://sfcheung.github.io/semfindr/reference/est_change.md)
  (DFTHETAS) or
  [`est_change_approx()`](https://sfcheung.github.io/semfindr/reference/est_change_approx.md)
  (approximate DFTHETAS) and `sort_by` is not `NULL`, then `sort_by`
  determines how the cases are sorted. If `by` is `"est"`, the cases are
  sorted as for the output of
  [`est_change_raw()`](https://sfcheung.github.io/semfindr/reference/est_change_raw.md).
  If `by` is `"gcd"`, the default for the output of
  [`est_change()`](https://sfcheung.github.io/semfindr/reference/est_change.md)
  or
  [`est_change_approx()`](https://sfcheung.github.io/semfindr/reference/est_change_approx.md),
  then cases are sorted by generalized Cook's distance or approximate
  generalized Cook's distance, depending on which column is available.

- ...:

  Other arguments. They will be ignored.

## Value

`x` is returned invisibly. Called for its side effect.

## Details

All the functions on case influence on parameter estimates,
[`est_change()`](https://sfcheung.github.io/semfindr/reference/est_change.md),
[`est_change_approx()`](https://sfcheung.github.io/semfindr/reference/est_change_approx.md),
[`est_change_raw()`](https://sfcheung.github.io/semfindr/reference/est_change_raw.md),
and
[`est_change_raw_approx()`](https://sfcheung.github.io/semfindr/reference/est_change_raw_approx.md),
return an `est_change`-class object. This method will print the output
based on the type of changes and method used.

## See also

[`est_change_raw()`](https://sfcheung.github.io/semfindr/reference/est_change_raw.md),
[`est_change_raw_approx()`](https://sfcheung.github.io/semfindr/reference/est_change_raw_approx.md),
[`est_change()`](https://sfcheung.github.io/semfindr/reference/est_change.md),
[`est_change_approx()`](https://sfcheung.github.io/semfindr/reference/est_change_approx.md)
