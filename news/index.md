# Changelog

## semfindr 0.2.0

CRAN release: 2026-03-06

### Miscellaneous

- Used precomputed vignettes to reduce the package size and also the
  speed to build vignettes. (0.1.9.1)

- [`est_change_raw()`](https://sfcheung.github.io/semfindr/reference/est_change_raw.md)
  will now keep the original order of parameters. (0.1.9.2)

- Updated terms to match those used in the manuscript. (0.1.9.3)

## semfindr 0.1.9

CRAN release: 2025-03-03

### Improvement

- Updated
  [`user_change_raw()`](https://sfcheung.github.io/semfindr/reference/user_change_raw.md)
  to allow for user functions that return an unnamed vector. Also added
  a `pkgdown` website article for
  [`user_change_raw()`](https://sfcheung.github.io/semfindr/reference/user_change_raw.md).
  (0.1.8.5)

- For
  [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md),
  added the argument `ncores` to make it easier to set the number of CPU
  cores to use in parallel processing. (0.1.8.7)

- For
  [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md),
  added the option to show a progress bar (generated by `pbapply`) by
  setting `progress` to `TRUE`. Enabled by default. (0.1.8.8)

### Miscellaneous

- Added [`on.exit()`](https://rdrr.io/r/base/on.exit.html) such that
  workers will be stopped if
  [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md)
  terminates abnormally. (0.1.8.2)

- Updated some default values of
  [`approx_check()`](https://sfcheung.github.io/semfindr/reference/approx_check.md)
  to reflect new features added to other functions. (0.1.8.4)

- Fixed a few Rd issues on CRAN. (0.l.8.6)

- Print a more conservative estimate of the expected time. (0.1.8.7)

- Remove an invalid link in the reference. (0.1.8.9)

### Bug Fixes

- Fixed a bug with
  [`index_plot()`](https://sfcheung.github.io/semfindr/reference/index_plot.md)
  when the extracted column has no names. (0.1.8.1)

## semfindr 0.1.8

CRAN release: 2024-04-08

### Others

- Updated the two tests for nonconvergence. Will check against results
  generated by directly calling `lavaan` functions. (0.1.6.1)

### Bug Fixes

- Fixed a bug with listwise deletion in
  [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md).

## semfindr 0.1.6

CRAN release: 2023-11-12

### New Features

- Added
  [`index_plot()`](https://sfcheung.github.io/semfindr/reference/index_plot.md)
  for generating an index plot for an arbitrary statistic. (0.1.5.5)

- Added
  [`user_change_raw()`](https://sfcheung.github.io/semfindr/reference/user_change_raw.md)
  for computing case influence on user statistics. (0.1.5.8)

### Others

- Fixed typos in the article on multiple-group models. (0.1.5.1)
- Fixed
  [`pars_id()`](https://sfcheung.github.io/semfindr/reference/pars_id.md).
  Users can now use the internal `lavaan` group labels (e.g., `".g2"`,
  `".g3"`) to denote parameters in a group. This method is not
  recommended (noted in the help page) but is included as an option.
  (0.1.5.2)
- Fixed an error at CRAN check due to suggested packages not installed.
  (0.1.5.3)
- Use [`lavaan::lavCor()`](https://rdrr.io/pkg/lavaan/man/lavCor.html)
  to estimate means and correlations for Mahalanobis distance when
  missing data is present. The package `norm2` is no longer needed nor
  suggested. (0.1.5.4)
- Made plot functions to work with NAs. (0.1.5.6)
- Updated `README.md`. (0.1.5.7)
- Finalized 0.1.6. (0.1.6)

## semfindr 0.1.1

- First public release.
- Added `skip_all_checks` to
  [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md),
  allowing users to experiment
  [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md)
  and other functions on models not officially supported.
- Revised
  [`est_change()`](https://sfcheung.github.io/semfindr/reference/est_change.md)
  and
  [`est_change_raw()`](https://sfcheung.github.io/semfindr/reference/est_change_raw.md)
  to support the use of operators (e.g., `~`, `=~`) to select
  parameters.
- Added badges and R CMD Check Action.
- Updated
  [`est_change()`](https://sfcheung.github.io/semfindr/reference/est_change.md),
  [`est_change_raw()`](https://sfcheung.github.io/semfindr/reference/est_change_raw.md)
  and
  [`est_change_approx()`](https://sfcheung.github.io/semfindr/reference/est_change_approx.md)
  to support models with labelled parameters. (0.1.0.9005)
- Added
  [`pars_id()`](https://sfcheung.github.io/semfindr/reference/pars_id.md)
  and
  [`pars_id_to_lorg()`](https://sfcheung.github.io/semfindr/reference/pars_id_to_lorg.md)
  for converting parameter specification to identification numbers (
  positions in the vector of coefficients or row numbers in the
  parameter tables). (0.1.0.9006)
- Updated `est_change_*` functions to use
  [`pars_id()`](https://sfcheung.github.io/semfindr/reference/pars_id.md)
  and
  [`pars_id_to_lorg()`](https://sfcheung.github.io/semfindr/reference/pars_id_to_lorg.md).
  (0.1.0.9007)
- Modified
  [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md)
  to use
  [`lavaan::lavaan()`](https://rdrr.io/pkg/lavaan/man/lavaan.html)
  instead of [`update()`](https://rdrr.io/r/stats/update.html) as the
  default way to rerun. (0.1.0.9008).
- Updated some of the tests. (0.1.0.9009)
- Added more examples. (0.1.0.9010)
- Updated documentation (e.g., README and DESCRIPTION). (0.1.0.9011)
- Updated
  [`influence_stat()`](https://sfcheung.github.io/semfindr/reference/influence_stat.md)
  and the plot functions to support the approximate approach.
  (0.1.0.9012)
- Updated documentation.

## semfindr 0.1.0

- Added more vignettes.

- [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md)
  can accept an output with inadmissible estimates. Disabled by default.
  Can be enabled by setting `allow_inadmissible` to `TRUE`.

## semfindr 0.0.4

- Added a print method for the
  [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md)
  class.

- Added
  [`mahalanobis_predictors()`](https://sfcheung.github.io/semfindr/reference/mahalanobis_predictors.md)
  to compute the Mahalanobis distance using only the observed
  predictors.

- Both
  [`mahalanobis_predictors()`](https://sfcheung.github.io/semfindr/reference/mahalanobis_predictors.md)
  and
  [`mahalanobis_rerun()`](https://sfcheung.github.io/semfindr/reference/mahalanobis_rerun.md)
  support datasets with missing data.

- [`lavaan_rerun()`](https://sfcheung.github.io/semfindr/reference/lavaan_rerun.md)
  can specify cases to exclude and rerun by specifying the case IDs or
  selecting cases based on Mahalanobis distance on all observed
  variables or on residuals of observed variables in a path model.

## semfindr 0.0.3

- Used `lavaan::update()` in lavaan_rerun. This is more reliable than
  recreating the call.

- Added
  [`implied_scores()`](https://sfcheung.github.io/semfindr/reference/implied_scores.md).
  It supports only single-group path analysis models for now.

## semfindr 0.0.2

- First internal testing release.
